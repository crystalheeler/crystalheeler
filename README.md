# Crystal Heeler's Widget Wonderland

Home Assistant add-ons by CrystalHeeler.

[![Add this repository to your Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fcrystalheeler%2Fcrystalheeler)

## Add-ons

| Add-on | What it does | Source and releases |
|---|---|---|
| **AnyCam** | Finds the IP cameras on your network (RTSP, ONVIF, MJPEG, HLS, RTMP) and shows them as live cards, with an Enhanced View and motion recording. | [crystalheeler/anycam](https://github.com/crystalheeler/anycam) |
| **OAK-D LR Camera** | Runs a Luxonis OAK-D LR PoE camera with on-device AI detection, an RTSP stream, motion recording and Home Assistant events. | [crystalheeler/Luxonis-OAK-D-LR](https://github.com/crystalheeler/Luxonis-OAK-D-LR) |

## Install

1. Select the button above. Or, in Home Assistant, open the add-on store, open the ⋮ menu, select **Repositories**, and add `https://github.com/crystalheeler/crystalheeler`.
2. Find the add-on in the store, then install it.

This repository holds only released versions. Each add-on's source, tests and change history are in its own repository.
